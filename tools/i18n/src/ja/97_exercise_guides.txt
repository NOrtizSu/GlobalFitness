# Machines
exg_machine_chest_press_steps = 1. グリップが胸の中央の高さに来るようにシートを調整します。\n2. 背中と頭をパッドにつけて座り、足を床につけてグリップを握ります。\n3. 腕がほぼ伸びるまでグリップを前に押し出します。\n4. プレート同士が当たらないようにして、胸にストレッチを感じるまでゆっくり戻します。
exg_machine_chest_press_tips = • 肩甲骨を寄せて下げ、パッドに押し付けておきましょう。\n• 最後に肘を伸ばしきってロックしたり、肩を前に丸めたりしないでください。
exg_machine_incline_chest_press_steps = 1. グリップが胸の上部の高さに来るようにシートを調整します。\n2. 傾斜したパッドに背中をぴったりつけて座り、グリップを握ります。\n3. 腕がほぼ伸びるまで斜め上に押し出します。\n4. 手が胸の上部の高さに来るまでゆっくり下ろします。
exg_machine_incline_chest_press_tips = • 肩甲骨を寄せたままにし、肩をすくめないでください。\n• 肩を守るため、肘は肩より少し低い位置に保ちましょう。
exg_pec_deck_steps = 1. グリップが胸の高さに来て、上腕が床と平行になるようにシートを調整します。\n2. 背中をパッドにつけて座り、肘を軽く曲げてグリップを握ります（またはパッドに前腕を当てます）。\n3. 大きな弧を描くように、胸の前でグリップを合わせます。\n4. 一瞬収縮させてから、胸全体にストレッチを感じるまでゆっくり開きます。
exg_pec_deck_tips = • 肘の軽い曲げ具合は最後まで変えないでください。押すのではなく、抱きかかえる動きです。\n• 腕を体より後ろに引かず、無理のないストレッチで止めましょう。
exg_machine_shoulder_press_steps = 1. グリップがほぼ肩の高さから始まるようにシートを調整します。\n2. 背中をパッドにつけて座り、足を床につけてグリップを握ります。\n3. 腕が頭上でほぼ伸びるまで押し上げます。\n4. コントロールしながら肩の高さまで下ろします。
exg_machine_shoulder_press_tips = • 腰をパッドにつけたままにし、重量を挙げるために背中を反らさないでください。\n• 上で肘を伸ばしきってロックしたり、肩をすくめたりしないでください。
exg_machine_lateral_raise_steps = 1. 肩がマシンの回転軸と一直線になるようにシートを調整します。\n2. 背すじを伸ばして座り、腕を体の横に下ろして前腕または肘をパッドに当てます。\n3. 肘が肩の高さに来るまで腕を横に上げます。\n4. 下でウエイトを休ませずに、ゆっくり元の位置に戻します。
exg_machine_lateral_raise_tips = • 肘から上げるように意識し、肩を耳から遠ざけて下げておきましょう。\n• 上体を後ろに倒したり反動を使ったりしないでください。コントロールできる重量を使いましょう。
exg_reverse_pec_deck_steps = 1. グリップを前側の位置にセットし、肩の高さに来るようにシートを調整します。\n2. パッドに胸をつけて向かい合わせに座り、腕を前に伸ばしてグリップを握ります。\n3. 腕が体と一直線になるまで、大きな弧を描くように横に開きます。\n4. 一瞬止めてから、ゆっくり前に戻します。
exg_reverse_pec_deck_tips = • 肘を軽く曲げたまま、後ろではなく横に大きく押し開きましょう。\n• 肩をすくめず、肩の後ろ側を使って動かしましょう。
exg_machine_row_steps = 1. グリップが胸の中央の高さに来て、腕を伸ばして届くようにシートと胸パッドを調整します。\n2. 胸をパッドにつけて座り、グリップを握ります。\n3. 肘を後ろに引き、肩甲骨を寄せながらグリップを胴体に引き寄せます。\n4. 腕が伸びて背中にストレッチを感じるまでゆっくり戻します。
exg_machine_row_tips = • 胸をパッドから離さず、上体を後ろに倒して重量を引かないでください。\n• 肘から引くように意識し、肩をすくめずに下げておきましょう。
exg_pullover_machine_steps = 1. 肩がマシンの回転軸と一直線になるようにシートを調整し、ベルトがあれば締めます。\n2. 腕を頭上に上げて肘をパッドに当て、バーを軽く握ります。\n3. バーがお腹の位置に来るまで、弧を描くように腕を前下方に下ろします。\n4. 広背筋にストレッチを感じるまで、ゆっくり頭上に戻します。
exg_pullover_machine_tips = • 背中に効かせるため、手ではなく肘で押しましょう。\n• 腰をパッドにつけたままにし、下で背中を丸めないでください。
exg_leg_press_machine_steps = 1. 背中とお尻をパッドにぴったりつけて座り、足を肩幅に開いてフットプレートの中央に置きます。\n2. フットプレートを少し押し上げ、セーフティレバーを外します。\n3. お尻がシートから浮かないようにして、膝が約 90 度になるまで曲げてフットプレートを下ろします。\n4. 足裏全体で押し戻し、膝がロックする手前で止めます。\n5. セットが終わったら、セーフティレバーを再びかけます。
exg_leg_press_machine_tips = • 膝はつま先と同じ方向に向け、内側に入らないようにしましょう。\n• 腰がパッドから浮いて丸まるほど深く下ろさないでください。\n• 上で膝を伸ばしきってロックすることは絶対に避けてください。

exg_horizontal_leg_press_tips = • かかとと足の中央で押し、膝はつま先と同じ方向に向けましょう。\n• お尻と腰をシートから離さず、膝をロックしないでください。

exg_hack_squat_machine_tips = • かかとを浮かせず、膝はつま先と同じ方向に向けましょう。\n• 足をフットプレートの高い位置に置くと臀部、低い位置に置くと大腿四頭筋に効きやすくなります。\n• 下でお尻がパッドから離れないようにしましょう。

exg_pendulum_squat_machine_tips = • 最後までかかとを床につけ、背中をパッドに押し付けておきましょう。\n• ゆっくり下ろし、下で反動をつけないでください。

# Timed holds and carries

exg_plank_tips = • 息を止めず、一定のリズムで呼吸しましょう。\n• お尻が下がったり上がったりしないよう一直線に保ち、床を見て首をまっすぐにしましょう。

exg_side_plank_tips = • キープしている間は、一定のリズムで呼吸しましょう。\n• お尻が下がったり前に回ったりしないようにしましょう。易しくするには下側の膝を曲げて床につけます。

exg_copenhagen_plank_tips = • 足首より膝をベンチにのせるほうが易しいので、そこから始めましょう。\n• お尻を高く一直線に保ち、一定のリズムで呼吸しましょう。

# Resistance bands
