# Band key help
band_help_title = 認証キー
band_help_what_title = 認証キーとは
band_help_what_text = バンドと Xiaomi アカウントが共有する、16 進数 32 文字（16 バイト）の秘密鍵です。Mi Fitness でバンドをペア設定すると、Xiaomi のサーバーが生成します。バンドはこのキーを使って、接続してきたスマートフォンが承認済みかどうかを確認し、通信を暗号化します。スマートフォン上で生成することはできないため、Mi Fitness または Xiaomi アカウントから入手する必要があります。
band_help_important_title = 重要
band_help_important_unpair = Mi Fitness でバンドのペア設定を解除する（または工場出荷時の設定にリセットする）と、キーは使えなくなります。再度ペア設定した後に、新しいキーを入手する必要があります。
band_help_important_share = キーを他人と共有しないでください：キーを持っている人は誰でもバンドに接続できます。
band_help_important_storage = このアプリはキーを非公開ストレージにのみ保存し、バックアップには含めず、診断にも表示しません。
band_help_how_title = 入手方法
band_help_how_text = 以下は Gadgetbridge プロジェクトで紹介されている方法です。このアプリがキーを抽出することはありません。
band_help_how_logs = Mi Fitness のログ（root 不要）：Mi Fitness（旧 Xiaomi Wear、パッケージ com.xiaomi.wearable）は、スマートフォンのストレージの Android/data/com.xiaomi.wearable/files/log/ にログファイルを書き込みます（Mi Health 版では Android/data/com.mi.health/files/log/）。これらのファイル（XiaomiFit.device.log など）で、後ろに 16 進数 32 文字が続く「encryptKey」、「authKey」、「token」、「huamiAuthKey」の各フィールドを検索します。複数ある場合は、ファイルの末尾に最も近いものから試してください。Android 11 以降では、通常これらのフォルダにはスマートフォンをパソコンに接続した場合（MTP または adb）にのみアクセスできます。
band_help_how_root = root 化したスマートフォン：Mi Fitness を終了し、そのデータベース「device_db」を確認します。キーは JSON「detail」の「auth_key」または「encrypt_key」属性にあります。
band_help_how_extractor = サードパーティ製ツール「Xiaomi Cloud Tokens Extractor」：パソコンで Xiaomi アカウントにログインすると、デバイスのキーが表示されます。サードパーティ製ソフトウェアのため、自己責任で使用してください。
band_help_enter_title = 入力方法
band_help_enter_text = 「認証キー」欄に貼り付けてください。先頭の 0x は省略可能です。スペースと改行は無視されます。
band_help_before_title = 接続する前に
band_help_before_text = バンドは同時に 1 つの接続しか受け付けません。Mi Fitness がバンドに接続している場合は、Mi Fitness を一時的に停止してください：設定 → アプリ → Mi Fitness → 強制停止。終わったら、Health Connect との同期を続けられるよう Mi Fitness をもう一度開いてください。このアプリが Mi Fitness を勝手に終了したり変更したりすることはありません。
band_help_more_title = 詳細情報
band_help_link_server = Gadgetbridge：キーの入手（Huami/Xiaomi サーバー）
band_help_link_devices = Gadgetbridge：Xiaomi デバイス
band_help_link_extractor = Xiaomi Cloud Tokens Extractor（サードパーティ）
