# Band key help
band_help_title = 认证密钥
band_help_what_title = 这是什么？
band_help_what_text = 这是一个由 32 个十六进制字符（16 字节）组成的密钥，由你的手环和你的 Xiaomi 账号共享。你在 Mi Fitness 中绑定手环时，Xiaomi 的服务器会生成该密钥。手环用它来验证正在连接的手机是否已获授权，并对通信进行加密。它无法在手机上生成：你必须从 Mi Fitness 或你的 Xiaomi 账号中获取。
band_help_important_title = 重要事项
band_help_important_unpair = 如果你在 Mi Fitness 中解绑手环（或将其恢复出厂设置），密钥将失效。重新绑定后，你需要获取新的密钥。
band_help_important_share = 请勿分享密钥：任何拥有密钥的人都能连接你的手环。
band_help_important_storage = 本应用仅将其存储在私有存储空间中，不包含在备份里，也绝不会在诊断信息中显示。
band_help_how_title = 如何获取
band_help_how_text = 以下是 Gadgetbridge 项目记录的方法。本应用不会替你提取密钥。
band_help_how_logs = Mi Fitness 日志（无需 root）：Mi Fitness（原名 Xiaomi Wear，软件包 com.xiaomi.wearable）会将日志文件写入手机存储空间的 Android/data/com.xiaomi.wearable/files/log/ 中（Mi Health 版本则为 Android/data/com.mi.health/files/log/）。在这些文件（例如 XiaomiFit.device.log）中搜索“encryptKey”“authKey”“token”或“huamiAuthKey”字段，其后跟有 32 个十六进制字符。如果有多个，请先尝试最靠近文件末尾的那个。在 Android 11 及更高版本上，这些文件夹通常只能通过将手机连接到电脑（MTP 或 adb）来访问。
band_help_how_root = 已 root 的手机：关闭 Mi Fitness，然后查看其“device_db”数据库；密钥位于“detail”JSON 的“auth_key”或“encrypt_key”属性中。
band_help_how_extractor = 第三方工具“Xiaomi Cloud Tokens Extractor”：在电脑上使用你的 Xiaomi 账号登录，它会显示你的设备的密钥。这是第三方软件：使用风险由你自行承担。
band_help_enter_title = 输入密钥
band_help_enter_text = 将其粘贴到“认证密钥”字段中，带或不带 0x 前缀均可。空格和换行符将被忽略。
band_help_before_title = 连接之前
band_help_before_text = 手环只接受一个连接。如果 Mi Fitness 正连接着手环，请暂时停止 Mi Fitness：设置 → 应用 → Mi Fitness → 强行停止。完成后，请重新打开 Mi Fitness，使其继续与 Health Connect 同步。本应用绝不会自行关闭或更改 Mi Fitness。
band_help_more_title = 更多信息
band_help_link_server = Gadgetbridge：获取密钥（Huami/Xiaomi 服务器）
band_help_link_devices = Gadgetbridge：Xiaomi 设备
