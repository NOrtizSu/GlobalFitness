# Band key help
band_help_title = La clé d'authentification
band_help_what_title = Qu'est-ce que c'est ?
band_help_what_text = Il s'agit d'une clé secrète de 32 caractères hexadécimaux (16 octets) partagée par votre bracelet et votre compte Xiaomi. Les serveurs de Xiaomi la génèrent lorsque vous associez le bracelet dans Mi Fitness. Le bracelet s'en sert pour vérifier que le téléphone qui se connecte est autorisé et pour chiffrer la communication. Elle ne peut pas être générée sur le téléphone : il faut l'obtenir depuis Mi Fitness ou depuis votre compte Xiaomi.
band_help_important_title = Important
band_help_important_unpair = Si vous dissociez le bracelet dans Mi Fitness (ou le réinitialisez aux paramètres d'usine), la clé n'est plus valable. Après l'avoir associé de nouveau, vous devrez obtenir la nouvelle clé.
band_help_important_share = Ne partagez pas la clé : quiconque la possède peut se connecter à votre bracelet.
band_help_important_storage = Cette application ne la stocke que dans son espace privé, hors des sauvegardes, et ne l'affiche jamais dans le diagnostic.
band_help_how_title = Comment l'obtenir
band_help_how_text = Voici les méthodes documentées par le projet Gadgetbridge. L'application n'extrait pas la clé à votre place.
band_help_how_logs = Journaux de Mi Fitness (sans root) : Mi Fitness (anciennement Xiaomi Wear, package com.xiaomi.wearable) écrit des fichiers journaux dans le stockage du téléphone, dans Android/data/com.xiaomi.wearable/files/log/ (dans la variante Mi Health : Android/data/com.mi.health/files/log/). Recherchez-y (par exemple dans XiaomiFit.device.log) les champs « encryptKey », « authKey », « token » ou « huamiAuthKey » suivis de 32 caractères hexadécimaux. S'il y en a plusieurs, essayez d'abord celui qui est le plus proche de la fin du fichier. Sous Android 11 et versions ultérieures, ces dossiers ne sont généralement accessibles qu'en connectant le téléphone à un ordinateur (MTP ou adb).
band_help_how_root = Téléphone rooté : fermez Mi Fitness et consultez sa base de données « device_db » ; la clé se trouve dans l'attribut « auth_key » ou « encrypt_key » du JSON « detail ».
band_help_how_extractor = Outil tiers « Xiaomi Cloud Tokens Extractor » : connectez-vous avec votre compte Xiaomi sur un ordinateur et il affiche les clés de vos appareils. C'est un logiciel tiers : utilisez-le à vos propres risques.
band_help_enter_title = La saisir
band_help_enter_text = Collez-la dans le champ « Clé d'authentification », avec ou sans le préfixe 0x. Les espaces et les retours à la ligne sont ignorés.
band_help_before_title = Avant de vous connecter
band_help_before_text = Le bracelet n'accepte qu'une seule connexion. Si Mi Fitness y est connecté, arrêtez Mi Fitness temporairement : Paramètres → Applications → Mi Fitness → Forcer l'arrêt. Une fois terminé, rouvrez Mi Fitness pour qu'il continue de se synchroniser avec Health Connect. Cette application ne ferme ni ne modifie jamais Mi Fitness de sa propre initiative.
band_help_more_title = Plus d'informations
band_help_link_server = Gadgetbridge : obtenir la clé (serveur Huami/Xiaomi)
band_help_link_devices = Gadgetbridge : appareils Xiaomi
band_help_link_extractor = Xiaomi Cloud Tokens Extractor (tiers)
