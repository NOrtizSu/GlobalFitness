# Band key help
band_help_title = Kunci autentikasi
band_help_what_title = Apa itu?
band_help_what_text = Ini adalah kunci rahasia berisi 32 karakter heksadesimal (16 byte) yang dimiliki bersama oleh gelang dan akun Xiaomi Anda. Server Xiaomi membuatnya saat Anda menyambungkan gelang di Mi Fitness. Gelang menggunakannya untuk memeriksa bahwa ponsel yang terhubung memiliki izin dan untuk mengenkripsi komunikasi. Kunci ini tidak dapat dibuat di ponsel: Anda harus mendapatkannya dari Mi Fitness atau dari akun Xiaomi Anda.
band_help_important_title = Penting
band_help_important_unpair = Jika Anda membatalkan penyambungan gelang di Mi Fitness (atau meresetnya ke setelan pabrik), kunci tidak akan berfungsi lagi. Setelah menyambungkannya kembali, Anda harus mendapatkan kunci yang baru.
band_help_important_share = Jangan bagikan kunci ini: siapa pun yang memilikinya dapat terhubung ke gelang Anda.
band_help_important_storage = Aplikasi ini hanya menyimpannya di penyimpanan pribadinya, di luar cadangan, dan tidak pernah menampilkannya di diagnostik.
band_help_how_title = Cara mendapatkannya
band_help_how_text = Berikut adalah metode yang didokumentasikan oleh proyek Gadgetbridge. Aplikasi ini tidak mengekstrak kunci untuk Anda.
band_help_how_logs = Log Mi Fitness (tanpa root): Mi Fitness (sebelumnya Xiaomi Wear, paket com.xiaomi.wearable) menulis file log ke penyimpanan ponsel, di Android/data/com.xiaomi.wearable/files/log/ (pada varian Mi Health: Android/data/com.mi.health/files/log/). Cari di dalamnya (misalnya di XiaomiFit.device.log) kolom “encryptKey”, “authKey”, “token”, atau “huamiAuthKey” yang diikuti oleh 32 karakter heksadesimal. Jika ada beberapa, coba dulu yang paling dekat dengan akhir file. Di Android 11 dan versi lebih baru, folder tersebut biasanya hanya dapat diakses dengan menghubungkan ponsel ke komputer (MTP atau adb).
band_help_how_root = Ponsel dengan root: tutup Mi Fitness dan buka database “device_db”-nya; kunci ada di atribut “auth_key” atau “encrypt_key” pada JSON “detail”.
band_help_how_extractor = Alat pihak ketiga “Xiaomi Cloud Tokens Extractor”: login dengan akun Xiaomi Anda di komputer, lalu alat ini akan menampilkan kunci perangkat Anda. Ini adalah perangkat lunak pihak ketiga: gunakan dengan risiko Anda sendiri.
band_help_enter_title = Memasukkan kunci
band_help_enter_text = Tempel kunci di kolom “Kunci autentikasi”, dengan atau tanpa awalan 0x. Spasi dan jeda baris diabaikan.
band_help_before_title = Sebelum menghubungkan
band_help_before_text = Gelang hanya menerima satu koneksi. Jika Mi Fitness terhubung ke gelang, hentikan Mi Fitness untuk sementara: Setelan → Aplikasi → Mi Fitness → Paksa berhenti. Setelah selesai, buka lagi Mi Fitness agar tetap menyinkronkan dengan Health Connect. Aplikasi ini tidak pernah menutup atau mengubah Mi Fitness dengan sendirinya.
